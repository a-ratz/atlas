# Ententeich-Portal

Die [[stadtwerke-ententeich]] vergeben Ablesetermine bisher per Telefon und pflegen sie in
einer Access-Terminliste. Das Portal lässt Kundinnen und Kunden selbst buchen. Die
bestehenden Termine der nächsten zwölf Monate werden übernommen. Der Code liegt beim Kunden;
diese Demo hat keinen Checkout.

- **Stand:** Anmeldung und Buchung laufen auf der Testumgebung, der Import der Alttermine
  fehlt noch.
