# Federkiel-Migration

Die [[teichwerk-ag]] verwaltet Bestellungen seit 2004 in einer Access-Anwendung. Federkiel
löst sie durch eine Web-App ab. Agenten setzen um, gemessen an Golden Mastern, die am
laufenden Original aufgezeichnet werden. Der Code liegt beim Kunden; diese Demo hat keinen Checkout.

- **Ansprechpartnerin Fachseite:** [[greta-gans]]
- **Stand:** Durchstich Bestellsuche läuft, Datenimport der Altbestellungen fertig.
- **Eigene Regel:** Ein Altfehler wird nur korrigiert, wenn die Fachseite das bestätigt hat.
