Terrain Only

You cannot attack. Change one tile a turn; the terrain does the killing.

grasscatches fire if next to fire
watera unit that enters it drowns
icea unit that steps on slides one tile on, further only over ice
firekills a unit on or entering it; burns out after 2 turns (number = turns burnt)
chasma unit that enters it falls
wallblocks everything

W walker: walks to you, never into water, chasm or fire. C charger: once it sees you, runs at you through anything. Numbers show who acts first; a badge shows where each goes next (1↓ one step, 1↓↓ a charge, 1· stays). Red = a strike that lands if nothing stops it.

  1. You change one empty tile (or pass).
  2. Fire: old fires burn out, grass next to fire catches, units on fire die.
  3. Enemies act in number order.
  4. Enemies announce their next move.
